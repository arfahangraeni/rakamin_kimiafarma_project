# rakamin_kimiafarma_project
Kimia Farma mencatatkan performa bisnis yang sehat pada tahun 2020-2023 dengan total pendapatan bersih sebesar Rp 321,2 Miliar, keuntungan bersih Rp 91,2 Miliar (margin laba bersih ~28,4%), dan volume transaksi mencapai 672.458 kali. Tren pendapatan harian tergolong stabil (stasioner) di kisaran Rp 50–70 juta per hari.
